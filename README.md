- 在 Mac M1 上使用 VS Code 和 clang++ 编译、运行 C++ Hello World。
- 使用 UTM 安装 Ubuntu 22.04.5 LTS ARM64。
- 在 Ubuntu 中练习基本命令，并登录 GitHub。
