## 分支与提交说明

- `task2`：本次 C++ 基础语法与洛谷练习任务所在分支。
- 任务1的历史提交目前保存在 `main` 分支，`task2` 分支继承了这些文件。
- 后续任务分别创建对应的任务分支。
- 完成任务后，将对应分支的链接填写到培训文档的“任务提交处”。

## Task2：C++ 基础语法与洛谷练习

### 任务要求

学习 C++ 基础语法，在洛谷“入门1：顺序结构”和“入门2：分支结构”中各完成5题，保存每题源代码和成功运行结果截图。
